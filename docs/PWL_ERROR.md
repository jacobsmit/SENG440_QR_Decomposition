# Piecewise-Linear Approximation Error

Deliverable for Lesson 112, project requirements I: *"determine the
maximum error for three middle points"*.

Generated by `scripts/pwl_error_table.py`.
"Middle points" are the interior error extrema -- the approximation
meets the curve near each breakpoint and deviates most inside the
segment, so those interior points are where the error lives. They are
solved for exactly (f'(x) = segment slope), not sampled.

## 1. The notes' reference approximation (arctan)

```
arctan(x) ~=  0.928x            |x| <= 0.5
              0.644x + 0.142     0.5 < x <= 1.0
              0.644x - 0.142    -1.0 <= x < -0.5
```

In Q11 integer form, as the notes give it: 1900, 1319, 291, breakpoint 1024.

| segment | slope | middle point | error there | max \|error\| |
|---|---:|---:|---:|---:|
| [0, 0.5] | 0.928 | 0.2785 | -0.01317 | 0.01317 |
| [0.5, 1.0] | 0.644 | 0.7435 | -0.01851 | 0.01851 |

The third middle point is the mirror of the second, at x = -0.7435, error +0.01851 (arctan is odd).

**Maximum error of the notes' arctan: 0.01851** (1.85 % of full scale).

## 3. Comparison

| approximation | max error | vs notes' reference |
|---|---:|---:|
| notes' arctan (2 segments, Q11) | 0.01851 | 1.00x |
| this project, arctan (P=4, Q14) | 0.000272 | 68.2x better |
| this project, sin (P=4, Q14) | 0.000235 | 78.7x better |
| this project, cos (P=4, Q14) | 0.000325 | 57.0x better |

The notes' constants are round numbers chosen to be readable, not
minimax-optimal: a proper 2-segment fit on the same breakpoint already
halves the error at identical cost. The remaining gain is segment count,
which is free here because the index is a shift.

Error enters the QR result through the rotation coefficients, so it is
the *orthogonality* of Q that ultimately matters -- see the accuracy
suite, which measures |I - QQ^T| directly.
